# Vaultify App

I have built your video organizer app with a premium, glassmorphism design.

## Features
- **Add Videos**: Save links with titles, categories, and notes.
- **Categorization**: Organize videos by category (e.g., Travel, Music).
- **Notes**: Keep track of your thoughts for each video.
- **Local Storage**: Your data is saved automatically in your browser.
- **Premium Design**: Dark mode, gradients, and glass effects.

## How to Run
1. Open a terminal in the project directory.
2. Run `npm run dev`.
3. Open the link shown (usually `http://localhost:5173`).

## Project Structure
- `src/App.jsx`: Main application logic.
- `src/App.css`: Component styles.
- `src/index.css`: Global design system.
