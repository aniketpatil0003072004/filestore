# Smart Share Commands

You can now control how links are saved directly from the Share Sheet by adding specific keywords to your share text.

## 1. Silent Save (No App Open)
If you add one of these commands to the text when sharing, the link will be saved **silently** in the background to the correct category.

| Command | Target Category | Example Text |
|---------|----------------|--------------|
| `news` | YouTube News | "Check this youtube news" |
| `movie` | YouTube Movies | "New movie trailer" |
| `movie kannada` | YouTube Movies (Kannada) | "youtube movie kannada" |
| `movie hindi` | YouTube Movies (Hindi) | "Best movie hindi" |
| `song` / `music` | YouTube Music (Hindi) | "Nice song" |
| `song english` | YouTube Music (English) | "New english song" |
| `tech` / `review` | YouTube Tech | "Phone review tech" |
| `cricket` / `ipl` | YouTube Sports (Cricket) | "IPL highlights cricket" |

## 2. Interactive Save (Opens App)
If you **do not** type any of the above commands, the app will open and **ask you** which category to put the video in, even if you have Auto-Save enabled.

This gives you the best of both worlds:
- **Speed**: Type a command to save instantly.
- **Control**: Don't type anything to choose manually.
